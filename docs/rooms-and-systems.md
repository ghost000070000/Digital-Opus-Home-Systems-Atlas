# Rooms and systems

**Floor** — an optional grouping of rooms (Ground, Upper, Utility). Filter the atlas by floor. Rooms without a floor still appear.

**System** — a job (Internet, Heating, Backup Power). An item may belong to many systems. System views list members and the modeled blast radius if each member failed.

On the atlas, rooms draw as quiet hulls. Double-click a room chip (or a collapsed room node) to collapse that group.
